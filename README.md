# ☕ Java.my — Laboratório de Lógica e POO em Java

> Repositório de estudos práticos com foco em lógica de programação, orientação a objetos e estrutura de dados em Java.

---

## 📌 Sobre

Este repositório documenta minha evolução como desenvolvedor Java — desde os fundamentos de lógica até conceitos avançados de Orientação a Objetos.

Cada pasta é um módulo de estudo com exercícios resolvidos, anotações e projetos práticos.

> **"Entender o porquê antes do como."**  
> Cada exercício aqui foi feito com foco em entender a lógica por trás, não só copiar solução.

---

## 🧠 O que você vai encontrar

### 📁 `Java/` — Fundamentos
- Tipos primitivos, operadores, estruturas condicionais
- Laços de repetição (`for`, `while`, `do-while`)
- Arrays e manipulação de Strings
- Métodos e escopo de variáveis

### 📁 `OrientacaoObjetos/` — POO
- Classes, objetos, construtores
- Encapsulamento (`private` + getters/setters)
- **Herança** — reutilização e especialização de classes
- **Polimorfismo** — sobrescrita e sobrecarga de métodos
- **Abstração** — classes abstratas e interfaces
- Relacionamentos: composição vs. agregação

### 📁 `Heranca/` — Herança a fundo
- Cadeia de herança em múltiplos níveis
- `super` e `this`
- Casting entre tipos da hierarquia
- `instanceof` para verificação segura de tipo

### 📁 `Biblioteca/` — Projeto Prático
- Sistema de gestão de biblioteca
- Aplicação real de POO: classes `Livro`, `Usuario`, `Emprestimo`
- Regras de negócio implementadas em Java puro

### 📁 `LeetCode/` — Lógica & Algoritmos
- Problemas de lógica e estrutura de dados
- Foco em raciocínio algorítmico e otimização

### 📁 `ProjetoPackage/` — Organização em Pacotes
- Separação de responsabilidades com `packages`
- Boas práticas de estrutura de projeto Java

---

## 📈 Evolução do Aprendizado

```
Lógica básica → Métodos → Arrays
      ↓
Classes e Objetos → Encapsulamento
      ↓
Herança → Polimorfismo → Abstração
      ↓
Projeto real (Biblioteca, Calculadora)
      ↓
Spring Boot (AppCuidar+)
```

## 🛠️ Tecnologias

- **Java 17**
- **IntelliJ IDEA**
- Sem frameworks — Java puro para fixar os fundamentos

---

## 💡 Por que este repositório importa

Antes de usar frameworks como Spring Boot, precisei entender:
- Como funciona injeção de dependência manualmente
- Por que interfaces existem
- O que herança resolve (e o que não resolve)

Esse repositório é a prova disso.
